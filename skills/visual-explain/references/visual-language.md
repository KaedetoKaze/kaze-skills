# 通用视觉语言

本文件约束所有非纯文字视觉输出。目标是稳定传达语义，而不是套用固定审美模板。

## 信息层级

- 让主要结论拥有最高视觉权重；标题只说明主题，不与结论竞争。
- 将次要背景、注释和辅助网格降到更低对比度。
- 同一视图尽量只有一个主阅读方向，默认从左到右或从上到下。
- 通过位置、留白和边界表达分组，避免仅依靠颜色区分。

## 语义一致性

- 同一语义在一个视图中保持相同颜色、形状、线型和命名。
- 颜色表示稳定角色，例如主要路径、风险、成功或中性背景；不要随机装饰。
- 实线箭头表达确定的方向性流动；虚线表达弱关系、可选关系或间接关系时必须给出语境。
- 双向关系使用双向连接或两条清楚分离的单向连接。
- 包含关系使用位置和边界表达，不用箭头代替容器。
- 因果、控制、数据、时间和依赖关系不要共用一种未标注连接线。

## 文字与标注

- 标签靠近对象，使用用户语境中的术语。
- 短语优于段落；长解释放在视图外。
- 字号、对比度和行距在目标显示尺寸下可读。
- 连接线标签避免压线、重叠或与节点边界混淆。
- 缩写首次出现时给出全称，除非用户已经在当前语境中定义。

## 布局与几何

- 对齐同层对象，保持稳定间距和边距。
- 减少交叉线；必须交叉时用清楚的视觉区分。
- 节点大小服从内容和层级，不暗示不存在的数值比例。
- 数量、面积或长度承担数据编码时，必须与真实值一致。
- 为标题、图例、标注和交互控件预留安全区域。

## 色彩与主题

- 使用语义令牌而非将特定十六进制颜色写成通用规则。
- 同时依靠文字、形状或线型传达关键信息，颜色不是唯一通道。
- 前景与背景保持足够对比；明暗主题下都检查文字和连接线。
- 类别很多时优先重新分组或拆图，而不是持续增加近似颜色。

## 响应式与可访问性

- 在常见窄屏宽度下保持主要阅读路径；必要时改为纵向布局或分段。
- SVG 提供 `role="img"`、简洁 `<title>` 和说明主要结论的 `<desc>`。
- HTML 使用语义元素、可见焦点和键盘可操作控件。
- 动画尊重减少动态效果的偏好，并提供静态等价信息。
- 不依赖悬停才能获得关键结论。

## 完成标准

- 不看解释正文也能找到主要结论和阅读起点。
- 任一颜色、形状和连接线的语义在全图一致。
- 标签无明显截断、重叠或低对比。
- 视图缩小后仍能辨认主要结构；细节不足时采用分层或拆图，而不是压缩全部内容。
