# 图像渲染

本文件处理两类不同任务：在用户原图上添加确定性解释层，以及生成不承担证据责任的概念插图。两者不得混淆。

## 原图标注

用户提供的截图、照片、扫描件、图表或地图属于原始证据。

- 保留原始像素内容和纵横比；标注以独立叠加层呈现。
- 裁切、旋转、增强或透视校正会改变观察条件时，明确说明变换。
- 使用轮廓、半透明区域、引线、编号和图例定位证据。
- 标注避开关键细节；无法避开时使用外置标签和引线。
- 路径标明起点、终点、方向和必要的时间或距离含义。
- 多个密集标注采用编号并在图外解释，避免文字覆盖原图。
- 不补画原图中不存在的事实性对象，也不把推测画成已确认事实。

完成标准：移除叠加层后原始证据仍保持原貌；每个标注能准确回指对象，且不遮挡判断所需的细节。

## 生成式插图

生成式插图适合概念类比、氛围、教育场景和非精确的解释性画面。

- 先写清插图承担的单一解释作用，再设计场景和构图。
- 将精确标签、数值、流程箭头和拓扑放在独立的确定性图层中。
- 画面包含可能被误认为事实的对象、比例或空间关系时，降低写实暗示或附上说明。
- 用户提供参考图时，区分需要保持的内容、风格和可改变部分。
- 需要多张图时保持人物、物体、颜色角色和视觉隐喻一致。
- 生成后检查是否出现错误文字、额外对象、错误数量或与解释目标冲突的视觉线索。

完成标准：插图能强化指定概念，但用户不会把其中的数值、标签、比例或空间关系误认为证据。

## 组合图

当插图和精确信息同时存在时，采用分层组合：

```text
生成式底图：场景、类比、氛围
确定性前景：标题、标签、数值、箭头、图例
```

保持两层可分别修改。不要要求图像生成模型直接生成大量精确文字或数据图表。

完成标准：所有证据性内容都能追溯到确定性图层；替换底图不会改变事实含义。
