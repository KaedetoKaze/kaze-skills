# 确定性渲染

精确标签、关系、数值和证据性结构使用本文件中的表示。先按 `routing.md` 选定理想表示，再采用当前宿主支持的实现。

## ASCII、伪代码与树

适合终端、Markdown、调用关系、目录层级、短流程和简单分支。

- 让缩进直接表达层级，连接符只承担一种语义。
- 伪代码表达决策和顺序，不补充无关实现细节。
- 控制宽度，确保普通聊天窗口无需横向滚动即可读取。
- 名称与当前代码、领域术语或用户输入保持一致。

完成标准：仅凭缩进和少量连接符即可正确复述顺序、层级或分支。

## Markdown 表格

适合少量对象与精确属性的比较。

- 每列只表达一个稳定维度，单位写入列名或单元格。
- 保持相同类型数据的格式一致。
- 单元格出现长段解释时，改用分组列表或其他表示。
- 不用表格模拟复杂空间关系或多层拓扑。

完成标准：用户能沿一行比较单个对象，也能沿一列比较同一维度。

## Mermaid

适合宿主明确支持 Mermaid 时的流程、时序、状态、层级和关系图。

- 选择与语义相符的图类型，不用 `flowchart` 勉强表达所有问题。
- 节点文本保持简短；详细说明放在图外。
- 使用稳定方向，减少反向边和交叉连接。
- 仅使用目标宿主可靠支持的语法；不确定时采用基础语法。
- 无法确认宿主能渲染时，改用 ASCII、表格、SVG 文件或简洁文字。

完成标准：语法可解析，所有节点与连接均对应真实关系，渲染失败时仍有可读替代表示。

## 数据图表

图表只在数值形状比逐项数值更重要时使用。

- 条形图从有意义的基线开始；截断基线必须明确提示。
- 折线图用于有顺序的连续或时间数据，不把无序类别连接成趋势。
- 散点图用于两个数值维度，并标明单位和异常点含义。
- 饼图只用于少量、互斥且合计为整体的部分；否则使用条形图。
- 图例、坐标轴、单位、时间范围和数据来源足以还原含义。
- 数据点很少或用户需要精确查值时，优先表格或同时提供精简数据表。
- 不使用面积、体积或透视效果夸大差异。

完成标准：图形编码忠于原始数据，用户能说出比较对象、单位、范围和主要趋势。

## SVG

适合需要精确布局、分组、标注或定制视觉语义的静态图。

- 使用一致的坐标系、安全边距和语义样式令牌。
- 将箭头标记、样式和重复图形放入可复用定义。
- 所有连接路径明确设置填充与描边，避免闭合填充伪影。
- 提供可访问标题与描述；文字保持为可选择文本，除非字体路径是交付要求。
- `viewBox` 覆盖全部内容，并允许在不同容器中等比缩放。
- 输出文件时使用可识别的 ASCII 文件名；在支持的宿主中直接预览。

完成标准：在目标尺寸和窄屏缩放下无裁切，连接关系清楚，文本可读，辅助说明完整。

## 静态 HTML

适合需要响应式排版、多个协调视图或宿主能可靠预览的复杂解释页面。

- HTML 只承载单个解释主题，不扩张为完整网站或 Dashboard。
- 优先原生 HTML、CSS 和内联 SVG；只有确有需要且宿主允许时才引用依赖。
- 明确内容宽度、换行、溢出和窄屏布局。
- 关键内容在脚本失败时仍可读取。
- 若页面不包含有价值的交互，保持静态并省去脚本。

完成标准：页面在目标预览环境可打开，主要内容无需脚本即可理解，窄屏无横向内容丢失。

## 语义等价替代

理想实现不可用时，保留主要语义，而不是追求形式相似：

- 调用关系：SVG 或 Mermaid 可以替换为 ASCII 调用树。
- 简单流程：Mermaid 可以替换为编号步骤和条件分支。
- 数值趋势：交互图可以替换为静态图；无法画图时用带变化量的表格。
- 系统结构：复杂 SVG 可以替换为分组树加关键连接列表。

替代完成标准：理解目标与事实精度保持不变，允许损失装饰和次要视觉细节。
