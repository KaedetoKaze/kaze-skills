# 仅文字导入

当用户要求“只同步文字”“不下载图片”或“图片仅保留图题”时，执行以下规则。

## 全文读取

- 不以终端回显作为全文来源。若正文可能超过终端安全回显长度，先在工作区创建临时导出文件，从文件读取并转换。
- 完成 frontmatter、标题数、表格、图题、Callout 与临时 URL 检查后，立即删除临时文件。

## 图片与嵌入文件

- 不下载图片，不生成任何图片引用，也不要把图片占位写成 Callout。
- 每张图片仅输出一行 `图题：……`。优先使用飞书题注、图片 alt 或紧邻说明；压缩为一两句短标题，不要生成完整读图描述。没有可用文字时写 `图题：待补充`。
- 删除飞书临时 URL 与 `img`、`figure`、`source`、`cite` 标签。
- 对嵌入的 PPTX、附件或预览，保留所在表格或正文中的文字产物／评价；必要时写“文件本体未同步”，不要留下资源标签。

## 分栏与 Callout

- 每个 `grid`／`column` 分栏组都转换为 Markdown 表格。连续分栏组共享同一张表，不能拆成相邻的多张表。
- 分栏中的文字、图题或两者混排均放进对应单元格；表头、分隔行、每个数据行都必须独占一行。
- 飞书 `<callout>` 在 Vault 模式转为语义相符的 Obsidian Callout；仓库模式转为标准 Markdown 引用块，并保留标题和正文。

## 验收

- 不存在飞书临时 URL、`grid`、`column`、`figure`、`source`、`cite` 或 `callout` 原始标签。
- 图片仅以 `图题：` 出现，且不在 Callout 内。
- 每张 Markdown 表格的表头下一行是合法分隔行。
- 所有 Callout 前后有空行，并可在 Obsidian 阅读视图渲染。
